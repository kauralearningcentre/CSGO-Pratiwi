Setup Instructions (1-Minute Setup)

Bi-Directional Google Sheets Sync:

When updating your Apps Script code below, both doGet and doPost functions are enabled. Food Categories and Master Price Libraries sync automatically!

  1. Open a Google Sheet, click Extensions > Apps Script.
  2. Paste the script code below into the Apps Script editor (delete existing code).
  3. Click Deploy > New deployment (or update existing deployment).
  4. Select type Web app, set "Who has access" to "Anyone".
  5. Click Deploy, authorize permissions, and copy the Web App URL into the box above!
